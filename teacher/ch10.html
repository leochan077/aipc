1-2物聯網的三部分：智能冷氣怎樣自己開？

室溫：

控制器的規則：室溫高過 28°C → 開冷氣；否則關冷氣

生活用得着：冷氣設定溫度高一點（例如 25–26°C）可以慳電。智能冷氣就是由規則自動幫你控制。

感知SENSE

傳感器：量到室溫 27°C

決策DECIDE

控制器（小電腦）：27°C 不高過 28°C → 不用開

執行ACT

執行器：繼電器保持關，冷氣不開

網絡：控制器用 Wi-Fi 把數據傳到手機 App，人在外面也可以看室溫、遙控冷氣。

上一課的手機：三部分都在同一部機。物聯網：三部分可以分開放在家裏不同地方，用網絡連起來。

進階：室溫在 28°C 上下跳動，冷氣就會不停開關。可以設兩條線：高過 28°C 開、低過 26°C 才關（叫「遲滯」）。

1-3練習：這個裝置是傳感器，還是執行器？

量度室內的溫度和濕度

收集環境的資料 → 感知 → 傳感器。

收到訊號，轉 90° 打開門鎖

做出動作 → 執行 → 執行器（伺服馬達）。

發現有人行過走廊

「發現」是感知 → 傳感器（紅外）。

響起警報聲，同時閃紅燈

發出聲和光 → 執行 → 執行器（聲光報警）。

量度車尾和牆之間的距離

量度 → 感知 → 傳感器（超聲波）。

用小電流開關冷氣機的電源

開關電器 → 執行 → 執行器（繼電器）。

偵測空氣中有沒有煤氣

偵測 → 感知 → 傳感器（氣體）。

收到手機指令，開關客廳的燈

改變電燈的狀態 → 執行 → 執行器（智能開關）。

記法：量度、發現、偵測 → 傳感器（輸入）；開關、轉動、發出聲光 → 執行器（輸出）。

2-2練習：選對傳感器

溫室：太熱或太乾時，要通知農夫

「熱」是溫度，「乾」是濕度 → 溫濕度傳感器。

廚房：發現煤氣洩漏

量度空氣中煤氣的濃度 → 氣體傳感器。

停車場：自動認出車牌，再打開閘門

要「看」車牌上的字 → 鏡頭拍下圖像，再由電腦辨認。

水缸：不碰到水，量度水位有多高

從上面發出聲波，量回聲時間 → 知道和水面的距離。

花園：天黑後，燈自動亮起

要知道「天黑了沒有」 → 量度光線 → 光照傳感器。

洗手間：有人入來就開燈，沒有人就熄

偵測有沒有人在移動 → 紅外（人體感應）傳感器。

3-1執行器：控制器一聲令下，它就動手

繼電器

開關大電器

用小電流控制大電流的電子開關。控制器推不動冷氣機，就靠繼電器幫它開關。

生活：智能插座裏面就有繼電器，開關時會「咔」一聲。

進階：3.3V 小電流令線圈變成電磁鐵，吸合開關，接通 220V 電路。

伺服馬達

轉到指定角度

收到指令，就轉到指定角度（0°–180°），轉到就停。

生活：自動窗簾、智能門鎖、自動餵魚器、遙控車轉向。

進階：每 20 毫秒一個脈衝，脈衝闊約 1–2 毫秒，代表轉到 0°–180°。

智能開關

用手機開關電燈

連上 Wi-Fi 的開關：可以用手機 App、語音或時間表開關電燈。

生活：出門才記得未熄燈？用手機關；設定 23:00 自動關。

進階：手機指令經互聯網送到雲端伺服器，再傳到家中 Wi-Fi 的開關。

聲光報警

提醒有危險

蜂鳴器響＋紅燈閃，一看一聽就知道有危險。

生活：煤氣警報、火警鐘、泊車雷達。有聲又有光，聽障人士也看得到。

進階：蜂鳴器靠電流令薄片快速振動發聲；閃燈每秒不宜多過 3 次。

3-2練習：選對執行器

室溫高過 28°C，要開動用 220V 的冷氣機

控制器的小電流推不動冷氣機 → 用繼電器開關大電流。

天黑後，把窗簾轉到「拉上」的位置

要轉到指定角度／位置 → 伺服馬達。

出門後才發現未熄燈，想用手機關掉

連上 Wi-Fi，用手機 App 遙控 → 智能開關。

氣體傳感器發現煤氣洩漏，要立即提醒家人

響聲＋閃燈，最快提醒人 → 聲光報警。

自動餵魚器：每天 8:00 把飼料盒轉 90°，倒出飼料

要轉到指定角度 → 伺服馬達。

每晚 23:00，按時間表自動關掉睡房的燈

連上 Wi-Fi，可以設定時間表 → 智能開關。

END三句帶走

1

物聯網（IoT）＝物件＋傳感器＋控制器＋執行器，再用網絡連起來：會感覺、會決定、會動手。

2

傳感器負責感知（輸入）：溫濕度、光照、紅外、超聲波、氣體、圖像／視頻。

3

執行器負責執行（輸出）：繼電器、伺服馬達、智能開關、聲光報警。

徽章：第 1–3 關的練習全部做對（答錯可以再試），就會得到該關的徽章。
